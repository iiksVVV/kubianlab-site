# Сайт «КубианЛаб — умная тележка»

Статический сайт проекта (без сборки и зависимостей). Публикуется через GitHub Pages.

## Запуск локально

```bash
python3 -m http.server 8080
# открыть http://localhost:8080
```

или

```bash
npx serve .
```

## Структура

- `index.html` — единственная страница (все разделы)
- `css/style.css` — стили
- `assets/` — оптимизированные фото, логотипы, видео (сжатый фрагмент, 540p, без звука)

## Публикация (по подтверждению владельца)

1. Создать отдельный публичный репозиторий (например, `kubianlab-site`) — НЕ в репозитории рабочего ПО.
2. Загрузить содержимое этой папки в ветку `main`.
3. Включить GitHub Pages: Settings → Pages → Deploy from branch → `main` / `(root)`.

Секретов и ключей API в этой папке нет и быть не должно.
